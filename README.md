## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/your-username/cce-class3-guide.git

# Navigate into the project folder
cd cce-class3-guide

# Launch local server using batch file or npx http-server
OPEN_OFFLINE.bat
# OR
npx http-server ./ -p 8080
```

Open **`http://127.0.0.1:8080`** in Google Chrome or Microsoft Edge.
